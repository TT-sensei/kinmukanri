# 勤務管理

学校の職員室などで使う、シンプルな勤務管理アプリです。

## できること

- 職員名をタップして出勤・退勤を記録
- 退勤前に確認画面を表示
- 今日の勤務状況を一覧表示
- 過去日の勤務記録を確認・修正
- 月別の勤務日数・勤務時間・時間外・早出を集計
- 月別集計をCSVで書き出し
- 退勤忘れを設定時刻に自動処理。翌日以降にアプリを開いた場合も未退勤を確認
- 職員名簿の追加・並べ替え・削除
- JSONバックアップと復元
- 設定画面を4桁PINで保護

## 初期PIN

初期PINは **0000** です。

初回に「設定」を開くとき、このPINを入力してください。設定画面には「初期PINは0000。安全のため変更してください」と表示されます。PINを変更すると、その案内は表示されなくなり、「設定PINは変更されています」と表示されます。

## データについて

勤務データは利用している端末のブラウザ内に保存され、外部サーバーへ送信されません。

そのため、端末を変えたりブラウザの保存データを削除したりすると勤務記録が引き継がれません。大切なデータは「バックアップを保存」で定期的にJSONとして保存してください。

バックアップファイルには職員名と勤務記録が含まれます。学校外へ不用意に共有しないでください。

設定PINはバックアップファイルには含めません。バックアップを別端末へ復元しても、復元先端末のPINはそのままです。

## 勤務時間の計算

勤務開始・勤務終了・休憩時間を設定できます。

時間外勤務は、勤務開始前の早出と勤務終了後の残業を合計して表示します。勤務時間や設定を後から変更しても、すでに記録した日の勤務設定はその日の記録に保存されているため、過去日の集計は変わりません。

## 利用について

GitHub Pagesなどで静的HTMLとして動作します。外部APIやバックエンドは使用していません。

学校での利用を想定していますが、実際の勤務管理・服務管理上の正式な記録として扱う場合は、所属校・自治体・教育委員会等の運用ルールを確認してください。
